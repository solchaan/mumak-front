# mumak-front

Mumak의 프론트엔드 저장소입니다.

브라우저에서 음악 아이디어를 스케치하고, 작곡과 간단한 녹음을 할 수 있는 서비스를 목표로 합니다.

## 첫 버전의 목표

- 피아노 롤을 이용한 음표 편집
- 웹 악기와 드럼 패턴 재생
- BPM 설정 및 구간 반복 재생
- 마이크를 이용한 간단한 녹음
- 프로젝트 저장 및 오디오·MIDI 내보내기

현재는 저장소 초기화 단계이며, 애플리케이션 코드는 아직 구현되지 않았습니다.
